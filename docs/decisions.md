# Build decisions

- Build and test first with synthetic sidebars. The owner's real file remains an optional later compatibility test. Synthetic Windows coverage cannot establish compatibility with a real Windows sidebar.
- R1 accepted depth-limited warnings, invalid-pack and unsupported-version errors. Validate complete pack contents at the core boundary. Derive aggregate counts. Enforce a fixed HTTP(S) maximum at planning and execution.
- Count unselected tabs as by-choice skips. Preserve parser skips separately and account for cancelled work. Undo uses a session marker, owned tab IDs and serialized imports.
- R0 supplied the threat model before feature implementation. Independent release reviews must distinguish observed behavior from defaults and unverified claims.
- Use local branches and worktrees, and keep build dependencies in the root lockfile. No publishing. Working name Tab Mover. Free, no analytics. Store IDs and final domain await the owner.
- File transfer is the default desktop handoff. Browser API support and performance require measured evidence. Avoid a shutdown countdown unless supported by a dated official statement.
- S1. Chrome for Testing 158, synthetic local pages. Immediate discard lost the URL and title. Discard after committed load retained both and returned a replacement tab ID. With only required permissions, updates reported status without URL. Bound waits and leave slow tabs loaded. Grouping a pinned tab unpinned it. Group creation must specify the target window ID. An unfocused window and group title, color and collapse worked. In 300-tab immediate-discard throughput probes, batches of 10/25/50 took 9.673/11.494/9.118 seconds with peak descendant RSS of 1567/2558/4072 MiB. Max importer timer drift was 2 ms. Choose 10. These timing runs are separate from the post-load correctness check.
- S2. Isolated Chromium launches with synthetic 4 KiB, 64 KiB and 160 KiB fragments did not deliver an intact pack. Use file handoff across browsers. No supported fragment size is claimed.
- S4. Firefox runtime was unavailable. The grouping API shipped across versions 138 and 139. Use capability detection and Firefox 140 as the floor for the manifest data-collection declaration. See [Mozilla’s grouping announcement](https://blog.mozilla.org/addons/2025/04/30/webextensions-support-for-tab-groups/).
- The Mac had Chrome and Arc installed, with Chrome for Testing available for extension loading. Variations in native browser UI and macOS privacy prompts require the owner’s manual check. No Windows environment was available.
- Arc confirms December 22, 2026 as its desktop sunset date. The site countdown uses the visitor’s calendar date. [Arc announcement](https://arc.net/)
- Apple's individual Developer Program lists USD 99 annually or local equivalent. Signing and store submissions remain owner tasks. [Apple membership](https://developer.apple.com/help/account/membership/program-enrollment)
- Opera’s current FAQ describes Add to Opera from the Chrome Web Store. Actual prompts vary by installed version. [Opera FAQ](https://help.opera.com/en/faq/)
- Tauri uses its dialog plugin from Rust. Custom narrow commands handle IO and browser launch. The webview receives no general filesystem, opener or shell permission.
- Stryker 10.1.1 uses a compiler API removed from TypeScript 7. The build pins a compatible TypeScript 6 version. Only esbuild ran a dependency installation script during pnpm install.
- A selected empty Space is represented by a blank native window. Its setup tab is recorded for Undo, while the moved-tab count includes only imported sidebar tabs.
- Landing page Lighthouse run on the local production build measured performance 100 and accessibility 100. The web server exposes test builds on loopback only.
- Browser groups require contiguous tabs. Keep pinned tabs first, place a group at its first appearance and preserve source order within it. The plan reports when this changes the overall tab order.
- Native browser and converter validation used disposable synthetic profiles. Firefox can be rebuilt from the included AMO sources. The detailed owner checks cover the real sidebar, native handoff and browser versions outside the automated matrix.
- Pin Node 26.13.1 (Lithium LTS) in .nvmrc. [Node release announcement](https://nodejs.org/en/blog/release/v26.13.1/)
