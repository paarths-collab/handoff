# Privacy policy

Handoff reads the sidebar or pack you choose and processes it on your device. It has no account, telemetry, advertising or upload endpoint. The converter blocks outgoing connections after loading. Your exported files remain wherever you save them.

The extension uses tabGroups to recreate folder groups and storage for the last import and Undo. The last-import record stores the URLs scheduled to move, including successful, skipped and failed destinations, on this device. Starting a new import replaces the previous record. Undo is available only in the same browser session. Keep your browser profile private. You can remove extension storage by uninstalling it. If you choose to skip already-open tabs, it requests the optional tabs permission to compare URLs locally. If you choose bookmark mode or keep a bookmarks copy, it requests bookmarks permission to create folders and bookmarks. Opening a destination tab contacts that website through your browser.

The desktop app looks for the known Arc sidebar path and offers a file picker. It reads the selected sidebar and saves exports where you choose. To open Spaces in a browser profile you pick, it reads only the profile names, as the browser's own profile menu shows them, from that browser's profile list and launches the browser with the web addresses you confirmed. Handoff never reads passwords, cookies or browsing history. The password guide tells you how to move saved passwords yourself between Arc and your browser; Handoff never sees them. A diagnostic contains structural counts. You choose whether to copy and share it.
