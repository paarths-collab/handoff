# Recording and screenshot script

Use the tiny or typical synthetic fixture in a clean browser profile. Hide account names, the bookmarks bar and native file paths. Keep all destination browser tabs on synthetic pages.

| Frame | Product Hunt gallery (1270 × 760) | Chrome Web Store (1280 × 800) |
|---|---|---|
| 1 | Converter file chooser and local-processing note | Importer file chooser |
| 2 | Expanded Studio Space with nested folders | Preview showing selected Spaces |
| 3 | Four export formats | Options for Today tabs and folder grouping |
| 4 | Imported bookmark hierarchy in Safari | Created browser window, pinned tab and named group |
| 5 | Offline archive with one search match | Import result, skipped list and Undo action |

## 30-second demo

| Time | Picture | Voice |
|---|---|---|
| 0–5 s | Show an invented Arc sidebar with Studio and Personal Spaces | “I want these folders in my next browser.” |
| 5–10 s | Choose the local sidebar file | “Handoff reads the file here on my computer.” |
| 10–16 s | Expand Studio and inspect its tabs | “I can check the structure before moving anything.” |
| 16–23 s | Download bookmarks and import them in the destination | “I’ll save bookmarks and import the file into Safari.” |
| 23–30 s | Expand the imported folders | “Here are the same links, organized by Space.” |

## Before/after GIF

Capture a six-second loop. Hold the synthetic sidebar for two seconds, cut to its preview for two seconds, then show the same folder expanded in the destination for two seconds. Keep the folder at the same screen position in the first and last frame. Caption the two views “Arc sidebar” and “Imported bookmarks.”
