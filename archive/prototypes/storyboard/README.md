# Handoff film storyboard

Six 16:9 concept frames using the approved flat blue Handoff mark, black surfaces and Figtree typography. Archived design reference; see the archive README for its status. Scene navigation, account assignment, selection counts and a sequence preview are interactive. All data is synthetic; this page does not detect browser profiles, authenticate accounts, open tabs, import passwords or save exports.

1. Intro: Spaces converge on the mark.
2. Source: compact sidebar file preview.
3. Library: expand and select Spaces.
4. Accounts: map each Space to an existing Chrome profile.
5. Folders: bookmarks per profile, separate password-import guidance.
6. Result: one window per Space and the closing brand line.

The existing desktop `ProfileMover` opens URLs in selected browser profiles. Existing sessions belong to those destination profiles; Arc cookies are not transferred. Profile names are available where permitted; the user may need to open a profile to confirm its Google account. Account labels in these frames are illustrative and must not be represented as verified sign-in status.

Opening plain tabs does not recreate nested folders. The bookmarks export/import shown in frame five is a separate operation. Passwords also require the browsers' own export/import flow. These distinctions are part of the storyboard copy.

This is a separate visual exploration. It does not change the current homepage, desktop implementation, or existing Remotion film.
