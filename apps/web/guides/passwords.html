Move passwords separately

Handoff never sees your passwords. Export the CSV directly from Arc and import it directly into the destination password manager.

Export from Arc

In your Arc profile, open arc://password-manager/settings and use Export passwords. Confirm the system prompt and save the CSV somewhere private. The file contains readable passwords.

Import in your destination

  • Chrome — Open Google Password Manager → Settings → Import passwords.
  • Brave — Open Brave Password Manager → Settings → Import passwords.
  • Edge — Open Settings → Profiles → Passwords (or Microsoft Password Manager), then choose Import passwords.
  • Vivaldi — Open the Chromium password manager settings from Vivaldi’s password settings and choose Import passwords.
  • Opera — Open Settings, search for Password Manager, then open its Settings → Import passwords.
  • Firefox — Open Passwords → three-dot menu → Import from a File.
  • Safari — Open the Passwords app on macOS and choose File → Import Passwords.

Check the imported entries, delete the CSV and empty Trash or Recycle Bin. Repeat separately for other Arc profiles.
