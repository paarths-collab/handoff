Move from Arc to Safari

Bring your Arc Spaces into Safari as nested bookmark folders.

Import bookmarks

  1. Open the converter and choose your Arc sidebar file.
  2. Review the preview, select the Spaces to keep and download Bookmarks HTML.
  3. On newer macOS versions, choose File → Import Browsing Data from File or Folder and select the bookmarks file. On versions with the older menu, choose File → Import From → Bookmarks HTML File.
  4. Select the downloaded HTML file. Expand an imported Space and check its Pinned and Today folders.

Tabs import as bookmarks. Open the folders you need from the Bookmarks menu. Apple’s import guide
