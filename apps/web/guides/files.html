Find your Arc sidebar

macOS

In Finder, press Shift–Command–G, enter ~/Library/Application Support/Arc/, and select StorableSidebar.json.

Windows

Enter %LOCALAPPDATA%\Packages in File Explorer. Open the folder beginning with TheBrowserCompany.Arc_, then LocalCache\Local\Arc. Look for StorableSidebar.json.

You can work from a copy. Keep it private because URLs may contain access tokens.
